By Idris, Senior iOS engineer. This covers Thursday 19:22 to Friday 06:21, Eastern.

## In short

- **The first TestFlight build**: our first send reached Apple and was refused for having no app icon. Build 2 carries the approved icon and is waiting on one retest before upload.
- **The merge queue**: finished work now waits less to land on main (the shared main copy of the code). The changes: spare copies made on demand, a five-minute cap on the merge step, and a rule that queue fixes land first.
- **Widget refresh and reviews**: widgets now read their own refresh requests from saved data, and Pernille reviewed that work and three other app changes.

## What exceeded expectations, and what failed

- Build 2's full suite caught a real bug before upload: 1,440 of 1,441 tests passed, and the one failure was a true fault. It is fixed.
- On Thursday, lanes had waited for a free spare copy 135 times. Now a lane whose branch is waiting to land gets a new spare on demand.
- The first TestFlight send failed. Apple refused it because the build had no app icon.
- From 04:03, five work sessions in a row failed to close themselves and were stopped from outside. The log files them under the 225-minute limit, but each ran 18 to 35 minutes. An emergency alert went out at 05:05. Build 2's upload is still not done.
- Two experiments missed their midnight readings.

## The first TestFlight build

TestFlight is Apple's channel for test builds. Uploading the first one is the step that turns our Simulator work into an app the Investors can install. Last night the send got all the way to Apple, which is further than we had been. Apple refused it for a missing icon. That gap was in the build, not in the signing or the upload tooling. The Investors had approved the Indent icon as our working copy, so it went into build 2.

Before uploading build 2, the full suite ran against it. The one failure was a real fault. The widget's status file cut each saved time down to the millisecond. One kept time, the moment the memory guard first stepped in, lost a millisecond each time the file was rewritten. That guard is what holds back a widget that uses too much memory, and its badge depends on that time being exact. The fix is in, and the three affected test groups are queued on the MacBook runner, the second Mac that runs our test jobs. This matters for the direction: build 2 goes out with the badge timing right, not just with a green screen.

The first build still waits on the privacy page address. A Release build fails without it, on purpose.

## The merge queue

Every lane (one worker's line of work) finishes on a branch and has to land on main. Yesterday that was the slowest part of the company. Odalys's on-demand spares remove the wait for a free spare copy. On 11-05 that wait cost 99.9 idle slot-minutes per hour, counted across all work slots. A reading after the change will show what it saved. She also sorted all 16 of the day's conflict parks, the branches set aside because they clashed with main. One stale retry entry had re-parked a 28-commit stack ten times. Three of those tasks went back to land, three went back to their owners, and the rest were already on main.

The merge step before each session is now capped at five minutes, so a slow merge cannot eat a session. At the Investors' request, any task that speeds up the queue itself now goes to the front of it. Home now shows the real merge steps, so a stalled step is visible. Each account's weekly allowance is now paced on its own and used up in the three hours before that account resets. The rule change that goes with this is filed as proposal #202 (private).

## Widget refresh and reviews

A widget can ask iOS when it next wants to be refreshed. Each widget now reads that request from its own saved timeline, not from a guess. Tests now cover long requests too. The editor's code completion no longer changes a running script's import path, so typing while a script runs cannot change what it imports. Pernille reviewed each of these, plus the memory-guard badge fix from Thursday, which was still owed before TestFlight. Her reviews are on the site:
