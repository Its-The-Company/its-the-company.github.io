## Verdict

**PASS with one medium.** Nothing is dropped or reordered: the reflow keeps every non-whitespace character in
order for all 19 entries (n=19, the unit test's claim holds on the host too). Condition 1 is met: certifi's page
carries the 16,726 B MPL-2.0 text through its part and the "unmodified, as source, upstream" line. But the reflow
joins lines that were separate on purpose, so two copyright notices, the MPL Exhibit A block and parso's author list
read as run-on prose (M1). Fix it before the Day 13 upload. Three lows.

Coverage: every component that `audit.json` marks bundled has a row, except hacl, mimalloc and mpdecimal (T-0345,
known). libffi is correctly absent: STDLIB_MODE is `zip`, which cuts `_ctypes`. The Editor and Package installer
groups are empty because nothing in them ships yet, and the screen leaves empty groups out. That is correct.

Checked and fine: `Text(verbatim:)` for notice text and a `String` for the statement, so no Markdown is read
(Acknowledgements.swift:322, :329). Missing, empty or format≠1 file is an error, not an empty screen (spec row
"file missing or empty"). Sections are in file order, entries in file order, and an unlisted group still shows.
The VoiceOver row label is "name, licence" as spec 10 says. Rows and text come only from the JSON. Host:
`tests/acknowledgements_test.py` PASS 74 FAIL 0; `tools/mutants.py tests/acknowledgements_mutants.json` 33 of 33
killed, both new mutants included. I did not rerun the Simulator suite; nothing below needs it.

## M1 (medium): the reflow joins deliberate line breaks, so separate notices run together

`NoticeText.joins` (App/Acknowledgements.swift:152-157) joins any two lines with the same indent. It has no test for
whether the break was a 72-column wrap or a real end of line. The characters survive, but notices that the
licences say "shall be included" no longer read as separate notices. From the host run of the shipped code:

jedi-authors is unaffected because its lines start with "- ". The unit test cannot see this
(Tests/AcknowledgementsTests.swift:43-48), because it compares text with all whitespace removed.

Fix (Idris):
1. A line that starts with `Copyright`, `©`, `(c)` or `(C)` (after its indent) never joins the line above it.
   This fixes expat, pyflakes and requests-notice.
2. A banner line, one that starts and ends with a run of 3 or more of `*=-#` (for example
   `***** BEGIN LICENSE BLOCK *****`), is layout. Treat it like `isRule` (:162): it neither joins nor is joined.
   This fixes certifi.
3. Author lists: add a registry field `"layout": "lines"` in components.json for parso-authors. tools/acknowledgements.py
   emits it the way it emits `statement`. For such an entry, `NoticeText` keeps every source line as its own line
   and only splits paragraphs at blank lines. I tried a general "would the next word have fit" rule on the bundled
   text first. It also stopped about 57 real prose wraps in the PSF and Apache texts, so I don't recommend it.
4. Tests: one `XCTAssertEqual` per bundled case above on `NoticeText.paragraphs(entry.notice)`, plus a generic
   test that every source line starting with "Copyright" begins a shown line, for every bundled entry. Add one
   generator test and one mutant for `layout`.

## L1 (low): table and boxed rows wrap in body type and lose their alignment

`isTableRow` (:168) keeps CPython's release table and MPL sections 6 and 7
(boxed in `*`) line for line. That is right. But each row is about 72 characters in proportional type, so at phone
width it wraps. The columns and the right-hand `*` border fall in the middle of the next visual line. Text is intact,
but legibility is not. Fix: draw a block whose lines are all table rows in a horizontal `ScrollView` with
`.fixedSize(horizontal: true, vertical: false)` per line, so rows don't wrap. Whether table blocks may use a monospaced
face is a spec 10.4 question for Maren ("never monospaced"); this fix doesn't need her answer.

## L2 (low): part rows repeat or garble the version

AckRow and NoticeBlock show `"\(name) \(version)"` (:252, :300). That gives "Mozilla Public License 2.0, full text 2.0"
(sheet 01-list.png) and "django-stubs (in Jedi) as in Jedi 0.19.2". Fix: in components.json (mine, T-0345), rename
certifi-mpl to "Mozilla Public License, full text" (components.json:575). In Swift, when a version starts with
"as in ", show it in the footnote line ("as in Jedi 0.19.2"), not after the name. I take the registry half.

## L3 (low): the statement test finds libffi by position

tests/acknowledgements_test.py:170-171 reads `ack3["entries"][1]`. If the fixture's order changes, the test fails
for the wrong reason, or passes on a different entry. Fix: `next(e for e in ack3["entries"] if e["id"] == "libffi")`.
