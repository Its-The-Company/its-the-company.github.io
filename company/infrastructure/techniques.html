Considered and turned down (17)

Reasons in full in the catalogue's Rejected section.

The 17 lines
  • Rejected History window / observation masking. (A4; Complexity Trap: masking cut instance cost 9.8-57.1% on SWE-bench Verified, but lowered Gemini 2.5 Flash thinking 40.4 -> 36.4): Claude Code manages context; we cannot install a history processor (D2); 0 compactions in 40 sessions (C M11); our threads are short.
  • Rejected LLM-summarizing condenser. (A5; OpenHands "up to 2x" cost cut is second-hand, the post was unread for terms): Claude Code compacts; no problem to solve.
  • Rejected Auto-compaction tuning, context resets. (C R2): 0 compactions in 40 sessions.
  • Rejected Subagent cache TTL 1 hour. (C R1): 1h writes cost 2x base vs 1.25x; within-thread writes are 28.6M of 38.8M; net loss on API ratios.
  • Rejected Tool-creation reminder every step. (A9; Live-SWE-agent 62.0% -> 76.0% on 50 problems, one run): the prompt form is already Tenet 7; the per-step form needs a hook and would grow a shared 250-file tools/ with throwaway scripts (D3). Revisit with #6 replays.
  • Rejected Ranked repo map / tool index. (A10): no measured number anywhere; small repo.
  • Rejected Architect/editor split. (A11): +3.1 points = 4 of 133 for Sonnet + Sonnet (2024 models); our Fable/Opus planning and packets are already this shape.
  • Rejected One worked example in the prompt. (A13): 1.7 points on 300 with GPT-4 Turbo.
  • Rejected Localize-then-repair pipeline, AST search, spectrum fault localization. (B5, B6, B7): ablations read T-0195, status unchanged. Agentless, GPT-4o, Lite (Table 2, p. 25): true file found by prompting 78.67%, embeddings 70.33%, both 81.67%; class/function step from a skeleton 58.33% at $0.02 vs whole file 53.67% at $0.15; edit lines straight from files 47.00% at $0.18 vs 50.67% at $0.06...
  • Rejected Environment setup out of agent turns. (B11): mostly done (xc.sh, run.sh, named commands); 6% of commands in SWE-bench trajectories, not measured here.
  • Rejected Trained verifier, RL, fine-tuning, MCTS, population search over agents. (B12, B13; DGM about USD 22,000 a run): the model is fixed (D2); one live system.
  • Rejected Free agent-to-agent chat. (CooperBench: no success gain, up to 20% of steps on communication): use #8's written record instead.
  • Rejected Decentralized dispatcher. (DeLM's no-planner design): independent agents amplify errors 17.2x vs centralized 4.4x (Scaling, D); our Operator also carries Investor order.
  • Rejected Asynchronous LLM overseer. (SICA): prefix monitors reach at best 28.8% recall (FailProc); deterministic stops first.
  • Rejected Agent teams, --bare, disabling git instructions, durable session resume, standing monitor agents. (C R3-R7): more tokens, needs an API key, small gain, or no measured loss.
  • Rejected Fewer parallel agents on coupled work. (D8; CAID worse at 8 than 4 on Commit0-Lite): the 8-12 pool is the Investors' (D5); the transferable part is a dispatch habit (fill the pool across clusters, report when fewer independent clusters exist), kept as a note under #8, not a technique to test.
  • Already in use Already ours, nothing to adopt. native tool calls (A R1), edit formats (A R2, fixed by Claude Code), event log (A R3, ops/runs and log/events.jsonl), cache marks (A R4), one task per agent with a fresh context (C T3), escalate after failed attempts (C T13), Claude Code version pin and smoke test (C T14), roles and SOPs (D 10).
