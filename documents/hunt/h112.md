## Use

    python3 tools/wiki_views.py "Knot" "Morse code" --months 12
    python3 tools/wiki_views.py --tsv --end 2026-09 "Knot" "Juggle"      # for scripts

Columns: title, N-month total, median month, last month, note. `--tsv` columns, stable:
`title article total median last months note`. Defaults: English Wikipedia, agent `user`
(bots and spiders excluded), window = the N complete months ending last month.
Exit 0 ok, 2 usage error (nothing sent), 3 REFUSED (a 403, or 429 four times).

## What a lane needs to know

1. The pageviews endpoint answers 404 both for a missing article and for one with no views. The tool
   checks titles first with one MediaWiki query per 50 titles; MISSING comes from that check only.
2. Views on a redirect title count only the redirect page (Juggle, not Juggling). The tool follows
   one redirect step and names it in the note. Pass the article title when you know it.
3. The monthly endpoint's end date must be the month's last day. An end of the 1st returned only one
   day for the last month (first live run: Morse code September 1,922 against 63,990 for the whole
   month, n = 8 articles all short the same way). Fixed before commit; a test pins it.
4. Pageviews measure curiosity on English Wikipedia, not demand for an app. Compare subjects with
   each other; do not read a number as buyers.
