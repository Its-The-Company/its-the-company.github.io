Maren, 2026-10-24. Board line 204. Tests PITCH-12 (Runpy, #44), build plan Day 4-5 and section 6. Written before opening H150.md (Commandment 33).

## Result

- **Usable scripts: 41 of n = 113** Pythonista-targeting scripts (36%), from **30 of 58** repositories. 41 distinct blobs, no duplicates.
- Of the 41: 34 permissive (MIT 30, Apache-2.0 4; 24 repos), 7 copyleft (GPL-3.0 5, GPL-2.0 2).
- Not usable: 27 of 58 target repos have no licence file (all rights reserved), 1 NOASSERTION. The two largest collections, tdamdouni/Pythonista (246 search hits) and bopopescu/Pythonista-1 (117), have none.
- Freshness: 14 of the 41 sit in 7 repos pushed in 2024-2026; the rest last pushed 2014-2021.
- Spread: at most 6 usable scripts from one repo (ywangd/stash), then 3 (khilnani/jira.py, namuan/py-ios-scripts). Median length 79 lines.
- Modules in the 41: appex 24, console 22, clipboard 21, ui 10, dialogs 8, editor 7, objc_util 4, photos 2, sound 1, keychain 1. So `ui` (the hard module) appears in only 10 usable scripts.

## Method

1. `tools/runpy_corpus.py`. 24 code-search calls on `language:python`: "import dialogs", "import console", "import ui", "import clipboard", "import appex", "import editor", the first three again with `-repo:tdamdouni/Pythonista`, and `pythonista "import ui"` / `pythonista "import console"`. 7 s between calls (limit 10 a minute). 1,566 path hits in 1,068 repos (`H152-raw/hits.json`).
2. Each hit read once through the contents API, up to 12 files per repository (only the two big collections above were capped). The text was scanned in memory for import lines and 25 Pythonista call names and then dropped. Only the names are stored (`scan.json`). 1,223 files read.
3. A row goes into the corpus when the file has at least one Pythonista call (138 rows, 83 repos). `target = y` when the repo is named or described as Pythonista, or the file imports `appex`, or it uses a Pythonista-only call (appex.*, editor.get_*, console.hud_alert / input_alert / show_activity, dialogs.form_dialog / list_dialog, ui.load_view), or its calls span two modules. 113 rows are target = y. The 25 left at n are same-named modules in other frameworks (winup `ui.Button`, lass `dialogs.alert`, a `clipboard.get` in a desktop game).
4. Per repository: `gh api repos/{r}` for pushed_at, fork and archived, and `gh api repos/{r}/license` for the SPDX id. 404 = `none`. usable = y for any recognised SPDX id; `none` and `NOASSERTION` = n.

The build ran into no rate limits (no STOP in `H152-raw/fetch.log`). An earlier run that read licences for all 1,068 repos was stopped and rebuilt to read files first, so it spent about 1,000 core calls on nothing.

## Files

- `H152-raw/corpus.tsv`: repo, path, licence, usable, pushed, then fork, archived, pythonista_repo, modules, api_evidence, lines, blob_sha, target. **Count with `target == y`.**
- `H152-raw/hits.json`, `scan.json`, `repos.json`, `fetch.log`: caches. `python3 tools/runpy_corpus.py` rebuilds the TSV from them with no API calls.
- Nothing is copied: paths, licence names and call names only (Commandments 5, 6).

## Limits

- This is a sample, not a census. Code search ranks by best match and stops at 1,000 results per query, and the files past the 12-per-repo cap went unread. Both capped repos are unlicensed, so the cap does not change the usable count.
- A `ui`-only file in a non-Pythonista repo with one call name scores n. A few real `ui` scripts may be missed, which biases the `ui` count low.
- `loganbriggs08/Bitcoin-Clipper` (MIT, target n) is a clipboard-hijack script. It must never be run or used as a fixture.
- usable = y means the licence allows copying the script as a test input. The 7 GPL scripts carry copyleft terms if they are ever bundled. The safe set for any fixture that ships is the 34 permissive scripts.
- Code comments and READMEs read here are information only. Nothing in them was followed (rule 5).
