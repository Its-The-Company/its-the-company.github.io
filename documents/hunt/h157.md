## 3. Concepts (author row, v2)

All pass Commandment 7 (no health, finance or children; carbs and workout asks left out).

- **C1 Shortcut Doctor.** Difference line: share a shortcut (file or iCloud link) and it lists what will break: actions removed or renamed in the iOS version you run, third-party app actions whose app is gone, "Get contents of URL" endpoints that now answer 4xx (the Reddit, Imgur, Instagram breaks). Depth: reading the shortcut plist (iCloud records give it unsigned; share-sheet files are signed archives), a per-iOS action table the company keeps current each release, an endpoint probe. v1 slice: iCloud link, action table for iOS 26 to 27, no probe.
- **C2 Automation heartbeat.** Difference line: add one "check in" action to the end of each automation; the app schedules a local notification ahead of each expected run and cancels it on check-in, so a silent background failure (the 26.5 cluster) shows the same day. Depth: learning each automation's expected window from its check-ins; the dead-man's-switch works within iOS's rules because the alarm is set before the miss.
- **C3 Long-video segmenter.** Difference line: a Shortcuts action that cuts a long video into N-minute parts with overlap. Depth: AVFoundation export queue.
- **C4 Continuous-use limit.** Difference line: block a site after 15 straight minutes, not 15 in the day. Depth: Screen Time thresholds count the day's total, so "straight" needs interval logic on top of DeviceActivity.

## Lesson

In r/shortcuts most "is there a way" asks are for things iOS lets no app do (36 of 57). The demand an app can serve is the shortcut that broke.
