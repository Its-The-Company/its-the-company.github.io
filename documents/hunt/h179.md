Owner: Maren. Run 2026-10-24 17:47-17:57 ET (by `date`; GitHub terms pages saved in H179-raw/terms/, uncommitted, 537 KB). Parent: H163 C1 Irish mutation reader, ruled B (rulings-v2.md, H163 chair 17:21; PITCH-14). Raw: research/hunt/H179-raw/.

**Result.** The Irish engine has two real siblings, Welsh and Scottish Gaelic. One v1 engine serves both, because all three languages change the start of a word after a trigger word. Welsh even has a CC0 lexicon that tags every mutated form. They do not widen the parent's Day 30. On US ratings their learner shelves add 3.5-10.5 downloads a day, or 15.9-47.6 if blas. is counted, against HeyRua's 365-1,096. The share needed stays at 0.5%-1.9% (it was 0.5%-2.0%), so no letter moves. Each one is Day 30 D on its own. German is the only sibling with traffic: 102-305 a day, C at its own $2.99 comparator. But it needs a second engine (case from endings and governing words), and the "german cases" shelf has a clone wave of 10 of 25 since 2025-10-24, with none paid over 100 ratings. Manx has no paid comparator (G12 kill). Breton, Polish, Czech, Finnish and Icelandic are Day 30 D at their own prices, and each would need a second engine. There is also one finding for the parent. "Irish" (6751746734, free, 0 ratings, #5 under "irish grammar") says it is "a lexicon of Irish Gaelic and a morphological analyser for learners". Whether it marks mutations in pasted text is unread. It is a K163-2 candidate for the chair.

## Method (pre-registered 17:47 ET, before any search; `phrases.tsv`)

- Store: iTunes Search API only, US, limit 50, through tools/store_http.py (`H179-raw/pull.py`). There were 28 phrases in the first run (17:47) and 17 in the second, the difference phrases (17:50, `phrases_diff.tsv`). Every phrase was run beside a neighbour in the same call ("paired runs"; G2 in H164). No apps.apple.com page and no tools/store_hints.py (ruling ad5aedd1), so Pull is read only as "a top-10 app over 100 ratings". The compact table is `top50.tsv`. The raw JSON (`store/`, 16 MB) is left uncommitted, as in H119.
- Novelty: `desc_scan.py` reads every saved description (all 50 rows of every phrase) for a sentence that says the app reads the user's own text (paste, type any, scan, camera, analyse, highlight, colour-coded) next to a form word (case, gender, article, mutation, declension). It finds 35 apps (`desc_hits.txt`). I read every hit by hand, plus the full text of 11 apps.
- Sibling lane (rule written in `sib_lane.py` before sizing ran): the union of the top 10 under the language's grammar phrase and its learn phrase. An app is kept only if its name carries the language's name, which drops generalists (Duolingo, Babbel, Drops) and off-language apps. blas. (six Celtic languages) is counted once in the Celtic sum, never per language. The lane is `tools/sizing.py` at its defaults (G9), and Day 30 is `tools/window_share.py --launch 22 --days 30 90 --paid` (G6), scored on the H135 scale at the midpoint (G7).
- G12 price, fixed before window_share ran: the paid-up-front app with the most ratings in the grammar phrase's top 10 whose name carries the language. For German, where "german grammar" has no paid row, the price comes from "german articles".
- Lexicons: GitHub's Terms of Service (section H, API Terms) and Acceptable Use Policies were read at 17:53, before any GitHub call (`terms/`). The API allows reads at its rate. Licences were then read through the GitHub API only (`api.github.com/repos/<repo>/license` and `/readme`), 17:53-17:56 (`lexicon/fetch-log.tsv`). No other site was fetched.

## Which languages one v1 engine serves, and their traffic

The Irish build is trigger-word rules plus a lexicon that undoes the mutation to find the headword (PITCH-14). Welsh, Scottish Gaelic, Manx and Breton are the same kind of grammar: the start of a word changes after a trigger word. Each needs only its own trigger table and lexicon. The five case languages change word endings by case, and the case depends on the sentence. That is a morphological analyser plus case assignment, a second engine. By refill-21 item 2, those do not count toward the parent.
