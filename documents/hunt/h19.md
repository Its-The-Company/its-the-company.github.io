## Venues and what "votes" means on each
- **Logseq** (discuss.logseq.com, Feature Requests): the only forum of the five with the voting plugin on. 21 requests created in the window; the top one has **7 votes**. The list is ordered by all-time votes, so old requests dominate.
- **Obsidian** (forum.obsidian.md, Feature requests, 6,078 topics): no voting plugin; topic likes are the vote. The forum answered 503 after 8 pages, so I saw 105 requests created in the window (partial; not retried harder).
- **Anki** (forums.ankiweb.net, Suggestions for desktop and for AnkiMobile): no votes; likes. 144 and 39 requests in the window.
- **Trakt** (forums.trakt.tv, General and Mobile Apps): no feature category with votes; likes. 263 and 16 topics.
- **OpenStreetMap** (community.openstreetmap.org): has no feature-request category; editor requests live on GitHub (H20). Not counted here.
- New tool `tools/discourse_votes.py BASE PATH [--since] [--bumped] [--grep]`: ranks a category's topics by votes, then likes; `--categories` lists paths. Logseq redirects `feature-requests/7` to `feedback/feature-requests/7`; urllib follows it.

## What H19 tells us
1. Votes and likes in vendor forums are small numbers: the busiest request of the year in Logseq has 7 votes. Only Trakt crossed 100, and that was users asking for features back after a forced redesign (the H12 "forced move" pattern again).
2. Where a forced redesign leaves the API untouched, third-party clients catch the leavers within weeks. Trakt has 13 on the shelf. Forced moves are a signal for an existing shelf, not an empty one.
3. Hand to Ines for H21: Trakt users want exact watch time and per-show progress from their own history ("time spent in days, hours and minutes", Hank, 2026-07-04). That is the export job, and it is counted here: 204 likes on the thread that names it.

H19 (vendor feature votes: Logseq, Obsidian, Anki, Trakt): the year's top request has 7 votes in Logseq and 54 likes in Obsidian; only Trakt's V3 redesign drew hundreds (204, 78, 49 likes), and 13 iOS Trakt clients already serve it. Best C-; no B+.
