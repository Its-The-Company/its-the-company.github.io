## 0. Rules, written before the first data fetch and before any count

Written 2026-10-24 22:09 ET, committed 9de6a293 at 22:09:16 ET. Robots files and licence pages were read before this section (<span title="The starting recipe a lane uses to look for ideas. ### 0.1 Text and token set

- The articles are the 31 Irish Wikipedia revisions in research/hunt/H182-raw/coverage_articles.json (title, revid). I do not refetch them by revision id: en/ga.wikipedia robots.txt has `Disallow: /w/` and `Disallow: /api/` for every agent (copy in H206-raw/terms/en.wiktionary.org_robots.txt, same file as H182's wp_robots.txt), and revision fetches go through /w/api.php or /w/index.php. H182 took the same revisions from the public dump; its per-token log research/hunt/H182-raw/coverage_tokens.tsv (2,000 tokens, columns article, token, demutated, rule, headword, any_form) is the token set here. This is a deviation from the board line's "fetched by revision id", for the robots reason, and I say so.
- **Noun tokens** = tokens whose lowercase de-mutated form (column `demutated`) is listed by BuNaMo as a noun. Two sets, both reported:
  - S1: the form equals a BuNaMo noun headword.
  - S2: the form equals an inflected form listed under a BuNaMo noun but is not itself a noun headword.
- BuNaMo is read locally from research/hunt/H182-raw/dl_bunamo/bunamo.zip (ODbL 1.0; the local test read is allowed, H176 K176-L1). It is the reference only; nothing derived from it is written beyond the counts.
- Reference lemma = the BuNaMo noun headword(s) the form matches; reference gender = that noun's gender attribute. If the form matches more than one BuNaMo noun and their genders differ, the token is "ambiguous"; a source agrees if its gender matches any of them. Ambiguous counts are printed.

### 0.2 The two shares, per source

Over S1, and over S1+S2, counting tokens (distinct forms also printed):

1. **Lemma-and-gender share** = tokens for which the source gives both a base form (lemma) and a gender (m or f) for the de-mutated form.
2. **Agreement share** = tokens whose source gender equals BuNaMo's. Printed with two denominators: all tokens in the set, and tokens where the source gave a gender.

A source that gives a lemma but no gender scores 0 on share 1 for that token; the lemma-only count is printed beside it.

### 0.3 How each source gives a lemma and a gender

- **A. Wiktionary, Irish entries.** The Wikimedia API (/w/api.php) and REST (/api/) are barred by robots.txt for every agent, as above; the only allowed action, `mobileview`, is not a lookup of entry wikitext. So Wiktionary is read from a published extract instead: kaikki.org's Irish JSONL (a wiktextract dump of en.wiktionary; kaikki.org/robots.txt disallows only /dictionary/search/*). An entry counts when `lang_code == "ga"` and `pos == "noun"`. If `word` equals the form: lemma = word, gender = the tag `masculine` or `feminine` on the entry's head_templates/senses/forms. If the entry is a form-of entry (`senses[].form_of[].word`), lemma = that word and gender = the lemma entry's gender. A form matched by both: the headword entry wins. Terms: Wiktionary content licence from Wikimedia's own pages; kaikki's own statement quoted from its pages.
- **B. UniMorph gle.** github.com/unimorph/gle, file `gle` (lemma, form, features). Rows whose form equals the de-mutated form give lemma = row lemma; gender = MASC or FEM if the features carry it, else none. Several rows with different lemmas: counted "ambiguous lemma", agreement on any.
- **C. A public-domain dictionary in machine-readable form.** Searched through GitHub's documented REST search (terms read in H179) and the Internet Archive's search API (terms read in H182). Counted only if a file with headword and gender exists and its digitisation licence is stated on the holder's own page. Otherwise a dated "not found".
- **D. Gender predicted from endings** (our own rule, no licence). Lemma = the de-mutated form itself when it is a BuNaMo headword (S1); the rule gives no lemma for S2 forms, so its lemma share over S2 is 0 by construction. Gender, first matching rule wins, on the lowercase form:
  1. ends in `ín` → m (diminutive);
  2. ends in `óir`, `eoir`, `úir`, `éir`, `aire`, `éara` → m (agent nouns);
  3. ends in `óg`, `eog`, `lann`, `acht`, `íocht`, `áil`, `int`, `irt`, `úint`, `is`, `ís` → f;
  4. ends in a vowel (a e i o u á é í ó ú) → m;
  5. otherwise the final consonant cluster: if the vowel before it is `e` or `i` (a slender ending) → f; else (broad ending) → m.
  No exception list. The rule is not tuned on the data; it is written here first and the script applies it verbatim.
- **GPL sources** are listed apart (section 2) and not counted.

## 4. Read against refill-24 section 6 (opened 22:12 ET, after fe4889bf)

Section 6 sets C (lemma and gender) and G (agreement) on "the tokens of those revisions ... that BuNaMo lists as nouns". My S1 is that set read by form; S1+S2 adds inflected forms. Against its three rules:

- **L206-1 (lift; C at least 90%, G at least 95%, licence and precedent quoted):** no source meets it. A's C is 83.5% (S1) and 79.3% (S1+S2). B's C is 0.6%. D has no G above 81.5%.
- **L206-2 (scope only; C 75% to under 90%, G at least 95%):** A, Wiktionary through kaikki, sits in this band on both sets: C 83.5% / 79.3%, G 98.5% / 98.6% of tokens given a gender (82.2% / 78.2% of all tokens). Its licence is quoted (CC BY-SA 4.0 and GFDL, commercial use allowed, share-alike on adaptations) and a store precedent is quoted (Wikimedia's Wikipedia iOS app statement, version-less). If the applier accepts the kaikki extract as "Wiktionary's Irish entries" (the API is barred by robots; the extract is the same dump), L206-2 applies: PITCH-14 names the source and the share "gender unknown" (16.5% of S1 tokens, 20.7% of S1+S2 by form; fewer once non-noun homographs are set aside).
- **K206-1 (no route):** does not fire, because A clears C 75% on both sets. If the applier does not accept the extract in place of the API, no source read through an allowed path clears 75%, and K206-1 applies.

Two caveats for the applier: section 6 says "G at least 95%" without saying which denominator; A passes on the given-gender denominator and fails on the all-tokens one (82.2%). And the Wikipedia app statement names CC BY-SA without a version.
