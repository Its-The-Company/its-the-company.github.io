## 0. Rules written before the first fetch (23:45-23:47 ET by `date`; committed before any read)

Rules bind from research/hunt/refill-24.md section 3 and refill-25.md section 2, unchanged.

**Paid tools (fixed now).** Language Reactor (Pro tier), Lingopie, Migaku, LingQ. "Others the reads find" are named in prose with the post that names them, not given a price row unless their own permitted page states the price.

**Hosts, each with robots.txt read and then its terms page read before any other page.** Robots.txt is saved by `H214-raw/bin/get.py robots` and every URL is matched by `get.py` (tools/robots_rules.py, group `*`) before it is sent; every request goes through tools/terms_guard.urlopen. A path the robots.txt disallows is a <span title="A figure we could not read because the source&#x27;s terms or robots file do not let our software read it. It never lowers a grade.">G2 gap</span>, recorded, not read. Terms are looked for at the host's own terms paths (`/terms`, `/terms-of-service`, `/tos`, `/legal/terms`, `/terms-and-conditions`); a host whose terms page cannot be found or read, or whose terms forbid automated access, is a G2 gap and its prices are not read. A human check (Cloudflare, CAPTCHA) stops the host (Commandment 7). Hosts: languagereactor.com (and www.), lingopie.com, migaku.com, www.lingq.com, for prices; studio.blender.org, for one lawful subtitle route (Creative Commons open films). Already ruled and cited, not re-read: Arctic Shift (H173, H209). No apps.apple.com, Amazon, Etsy, Goodreads, Gumroad. No iTunes Search, chart RSS, review RSS or storefront Lookup; bare Lookup only for ids already on file, file named.

**Prices.** Only from the maker's own page, after its terms; currency and billing period as printed; fetch time kept. A price seen only in a post is "post-stated, not sourced" and goes in no price cell.

**Demand venues, 30 days, hand-read.** r/languagelearning and r/LearnJapanese through `tools/post_search.py` (Arctic Shift), `--after 2026-09-24`, limit 100. Queries, in this order, none added after the first call: "language reactor", "lingopie", "migaku", "subtitles", "known words", "netflix". A refused query is retried once by the tool and then logged unread, not replaced. Every hit's title and body hand-read, deduplicated by post id, <span title="A measured fact that holds a grade below a letter, however good the rest is.">cap</span> 150 posts per venue (newest first). Codes, one per post: **P** = states paying for, or a price of, a named paid tool; **A1** = asks for C1's computation (below); **A2** = asks for C2's computation; **A0** = asks for H72's coverage or level computation (counted for H72's file only, not this lane's need); **U** = uses or asks about a named tool, no price, no computation ask; **X** = other. Asks a day = distinct A posts / 30, a floor (full-text search is not the post stream).

**Concepts (fixed now; each names input, output, rival to check).**
- **C0** Which show is at my level, with the primer: H72's. Sent there.
- **C1** Own-file study player: the learner's own video file and its .srt or .vtt, played with tap-to-look-up dual subtitles on iPhone; the app logs each lookup against the cue and estimates per-word "known" from the learner's own lookups across files. Input: own video + subtitle file + taps. Output: a known-word list that grows from viewing, and per-file lookup density. Rivals to check: Language Reactor, Lingopie, Migaku, LingQ by their own pages.
- **C2** Saved-words review from a service's own export: the learner's saved words with sentence context, exported through the service's documented export (Language Reactor, LingQ, Migaku), scheduled for spaced review and grouped by show, with "saved but still looked up again" computed across exports. Input: the learner's own export file. Output: schedule and relapse list. Route: only if the service's terms or help pages document the export for the user.

**Subtitle-file route rule (refill-25 H214; Commandment 6).** For C1 and C2 the lane records each route a learner has to a subtitle file that is theirs to process: (a) a file they wrote; (b) a Creative Commons or public-domain film whose licence covers the subtitles (Blender open films, licence read on studio.blender.org); (c) a streaming or catalogue service's own download, counted only if that service's terms say so in words read here; (d) a disc rip, not a route; (e) OpenSubtitles and similar catalogues: H72 found their terms walled; not re-read, still not a route. **<span title="A test written in advance. If it fires, we drop the idea.">Kill</span> at <span title="Whether we may and can build it: our rules and banned areas, and a first version Idris can finish by Day 22. A subject off the Investors&#x27; list is noted, not dropped.">Fit</span>:** a concept whose input has no lawful route beyond (a) and (b) is killed at Fit with the reason printed, since films and TV the learner watches are almost never (a) or (b).

**Store cells.** <span title="How many apps on the shelf already sell the same thing.">Crowding</span> and <span title="The rule that decides whether an idea gets two blind graders now, waits (park), or stops.">T1</span> <span title="The App Store results a buyer sees for a search phrase.
