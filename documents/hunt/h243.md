## 0. Section 0 (written 2026-10-25 04:59 ET by `date`, before any fetch and before any <span title="One numbered piece of research into one area of ideas. Each lane has its own file.">lane</span> script)

**Commandments.** `python3 rules/lookup.py 7` was run before this section. A dataset or ask in a C7 area (finance, medical or health, legal, gambling, adult, weapons and substances, children under 13, politics) or one that needs other people's personal data, payments or outreach (C6, C10, C58) is coded OUT before clustering.

**Hacker News.** hn-terms-ruling.md items 1 and 2 bar Algolia HN Search and news.ycombinator.com scripted reads pending the Investors; item 3's Firebase API has no text search and needs known ids, which a dataset ask search does not have. So the HN venue is written **refused (terms)** for every dataset, never 0, and no HN query is sent. The board line's "4 HN queries" become 4 GitHub queries. Apple store paths are not touched (#53).

**Fetch path.** Every request through tools/terms_guard.py: lane scripts in H243-raw/bin use terms_guard.fetch only, and `python3 tools/lane_fetch_check.py --lane H243` must pass before the first fetch. GitHub issue search through tools/gh_asks.py (unauthenticated, terms_guard). No dataset file is downloaded: R30-3 needs only the licence, quoted from the dataset's own page. Raw saves are text extracts, kept small.

**Terms, in this order, each before its first data fetch:**
1. GitHub Terms of Service and Acceptable Use Policies (docs.github.com site-policy pages), re-read for this lane and quoted in section 1. If they bar this use, the asks column is written refused.
2. Each dataset's own licence page (fetch reads that host's robots.txt first; a robots refusal or 403 is an unread licence, so the dataset is OUT under R30-3 "no licence stated", stricter reading).

**R30-3 coding.** IN: CC0, public domain (US federal works included), CC BY, ODbL, other open licences allowing commercial use; duties (attribution, share-alike) written beside the row. OUT: NC, ND, personal use, research only, no licence stated, or terms barring redistribution in an app. Quoted words decide; on doubt, OUT.

**Asks (cap 4 queries, GitHub only, R30-2 with R29-2's window 2026-07-27 to 2026-10-25 and count of 3).** One query each, in this order, for the first four datasets coded IN from this list: Q1 ListenBrainz, Q2 Tatoeba, Q3 OEIS, Q4 kaikki. A dataset coded OUT gives its query to the next IN dataset not yet queried in D order (D1, D6, D7, D8). Query form: `tools/gh_asks.py search '"<name>" is:issue created:2026-07-27..2026-10-25' --since 2026-07-27 --top 50`, 7 s apart, with <name> = listenbrainz, tatoeba, OEIS, kaikki (or the replacement's name: musicbrainz, openstreetmap, "USGS earthquake", wikidata). Raw output saved as printed.
- **An ask** (R30-2): a distinct account's issue or comment asking, in its own words, for something computed from the dataset (a statistic, ranking, match, recommendation, check or derived view), whether for a tool or from the maintainers. Not asks: bug reports, import or parser failures, data corrections, maintainers' and bots' posts, reactions (recorded, never counted). Coding is from the saved search text first (title and body excerpt); a thread opened for a full read has its repo's CONTRIBUTING fetched first through gh api and saved.
- **Count.** 3 or more asks for the same computation from the same dataset = met; 0 to 2 = <span title="An idea that reaches B or better but is held below B by a measured cap. No graders until a permitted reading lifts the cap.">parked</span> for need. HN is refused (terms) beside every count.
- **<span title="One product idea inside a lane. C1 is the lane&#x27;s first idea.">Concepts</span> (cap 4).** Only from a met or near-met computation (R30-3: no counted ask, no concept). Each concept row: dataset, licence and duties, the ask count with links, the output in plain words, and a money line only if a priced product doing the job is read from its own page (its host's robots and terms first; a barred host is a <span title="A figure we could not read because the source&#x27;s terms or robots file do not let our software read it. It never lowers a grade.">G2 gap</span>). Author table, no letters; <span title="How different the idea is from what the App Store already sells.">Novelty</span> and <span title="How much room the idea has to grow. It moves the grade up or down a step or two.">Depth</span> "not graded".

**Falsifier for this lane.** If no dataset reaches 3 counted asks for one computation, H243 yields no concept, and that counts toward F30-1 (refill-30.md section 7).

## 1. Terms read (04:59 ET, fetch-log.txt; terms/tos.txt, terms/aup.txt)

- GitHub ToS section H: "Abuse or excessively frequent requests to GitHub via the API may result in the temporary or permanent suspension of your Account's access to the API." No bar on reading public issues through the API; four searches, 7 s apart.
- GitHub AUP 7: "Researchers may use public, non-personal information from the Service for research purposes, only if any publications resulting from that research are open access." and "You may not use information from the Service ... for spamming purposes". Whether a company's product research is "research purposes" is the same open question as H242: left to the chair. Only titles, repo names and links are kept; no personal data.
- Hacker News: **refused (terms)** under hn-terms-ruling.md items 1-2; no HN request sent.

Here is the shape of it: on GitHub, these datasets show up as supply. Tatoeba's 50 are mostly builders wiring example sentences into their own dictionary and flashcard apps (35 W; dict-app alone has five tickets). People are building with the data, not asking for something computed from it. MusicBrainz and OpenStreetMap are infrastructure: their hits are library-manager bugs and the CARTO basemap "API KEY REQUIRED" watermark (5 of OSM's first 13).
