## 0. Sources, hosts, caps, codes (committed before any content fetch)

**What a seed must be.** A US utility patent filed 2002-01-01 to 2006-12-31 (so its 20-year term from filing has run, before any term adjustment, which only a status read can settle), whose claims describe a consumer measurement, an organisation method, or a learning method that an iPhone can now run on the buyer's own input (camera, microphone, IMU, LiDAR, their own text or files). A patent is a seed, never proof of demand. Subjects follow R33-2 item 5 (science and math, language, computer science, automation and organisation, notetaking, walking, data visualisation, data-driven film, TV and music).

**Fetch plan.** tools/terms_guard.fetch only, through H267-raw/bin/get.py (rules_first gate), one request per 2 s, fetch log H267-raw/fetch-log.tsv, page bodies in H267-raw/pages/ (only files under 1 MB committed). Order: preflight; then the first permitted search host, one CPC or keyword query per subject (at most 6), then at most one claims page per seed, stopping at 30 patents or 20 fetches. No API key, no account, no sign-up: a host that needs one is a <span title="A figure we could not read because the source&#x27;s terms or robots file do not let our software read it. It never lowers a grade.">G2 gap</span> (C50).

**Codes.** S = filed 2002-2006 and the source shows the filing date; S? = date not shown. X = a status line read and quoted (for example "Expired - Lifetime" or a fee lapse), dated; X? = no status read. P = the claimed method runs on an iPhone sensor or on the buyer's own files (one sentence, cited to the claim); P0 = needs hardware a phone lacks. C7 = a body measurement or C7 area (dropped). R = a priced rival on its own page; R0 = only a free rival; Rn = no rival read. L = a later live patent is cited on the rival's own page (note only). G2 = host gated (robots, terms, challenge, key).

**Gate.** If every host above fails the preflight, the lane stops at section 1 with a G2 gap Result and no concepts.
