## 0. Section 0 (written 2026-10-25 06:40 ET by `date`, before any query in this lane)

**Commandment 7.** `python3 rules/lookup.py 7` run at 06:39. Questions in banned areas are coded C7 and removed before clustering.

**Host.** api.stackexchange.com only, every call through tools/se_asks.py (which calls terms_guard.urlopen: live robots read each run; a refusal stops the run). Terms: stackapps.com API terms on file (H236 section 5, 43b0b430). No stackexchange.com web page is fetched.

**Seven sites.** apple (Ask Different), movies, linguistics, languagelearning, outdoors, opendata, and **academia** as the seventh (science research, reading and notetaking are Investor subjects; Data Science asks are mostly library help, Writing is near creation tools).

**Test 4, quota.** tools/se_quota.py at start: "252 left of 300, lane H237, 2026-10-25 04:15 EDT ... floor 50: ok". The R33-1 stop line "1,000 remaining" cannot be met by a keyless read: the keyless daily quota is 300, so the run would stop before its first call. I read it as the tool's floor (50) plus the lane <span title="A measured fact that holds a grade below a letter, however good the rest is.">cap</span> of 60 calls (leaves 190 or more by the start figure). Disclosed for the chair; if the chair <span title="What keeps an idea below the top: the cap that applies to it now.">holds</span> the literal line, every count below is void and the lane is "gap: quota".

**Test 3, recall control, per site, fixed here before any call.**
- Call L (listing): `se_asks.py SITE "" --since 2025-10-25 --n 100` (newest 100 questions in 365 days, any text). Saved as H269-raw/SITE-L.txt.
- Call C (control): the full title of the oldest row in that saved listing, punctuation turned to spaces, run as `se_asks.py SITE "<title>" --since 2025-10-25 --n 10` (q, full text, the same field the counting queries use). It must return 1 or more items **and** the listed question id among them. Otherwise the site is "gap" and gets no count queries.
- If call L itself returns 0 items or errors, the site is gap.

**Counting queries, per site that passes (4 calls, q full text, --since 2025-10-25, --n 100, --body):**
- apple: '"is there an app"', '"an app that"', 'calculate', 'spreadsheet'
- the other six: 'app', 'tool', 'calculate', 'spreadsheet'
has_more is written; rows past 100 are unread. Total cap: 7 sites x 6 calls = 42 of the 60 allowed.

**Codes, by hand on title and 300-character body.** A script first drops rows already seen in another query of the same site (by question id); every remaining row is coded by hand, none by regex.
- C7: banned area. Out.
- A0: asks for an app, tool or method that computes an output (number, schedule, plan, check, summary, chart, ranking) from the asker's own input (their files, lists, logs, measurements, text, photos), where the output is the point; 0 answers.
- A1: the same ask with 1 or more answers. Answers are not read (se_asks returns none), so "answered no such app" cannot be told from "answered with an app": A1 counts as an ask, its answer state unread.
- X: everything else (troubleshooting, data requests for a public dataset, how-to for an existing app, theory, career).

**Counts (R29-2 as written).** Windows: 90 days = 2026-07-27 to 2026-10-25; 365 days = 2025-10-25 to 2026-10-25, reported apart. A cluster is A rows by the output asked for; 2 or more A in 365 days makes a <span title="One product idea inside a lane. C1 is the lane&#x27;s first idea.">concept</span>, at most 4. A concept meets R29-2 at 3 or more A asks in 90 days on this venue; 0 to 2 is <span title="An idea that reaches B or better but is held below B by a measured cap. No graders until a permitted reading lifts the cap.">parked</span> for need. Each question cited by its Stack Exchange URL (attribution clause).

**Concept fields (R33-2 item 3).** Buyer; the computation on the buyer's own input; data and its licence from its own page (or "no outside data"); a priced rival's own page, or "no priced rival found" (a <span title="Our arithmetic estimate of what the idea would earn by day 30 (the $200 deadline) or day 90. It never raises a grade.">Day 30</span> doubt). Price pages are not fetched in this lane unless an asker or answer names the tool (cap 4 fetches, terms and robots first); a store read is G2 (#53).
