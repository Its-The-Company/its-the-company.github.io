Direction B, screen 1: Projects

B is a programmer-first workbench. It shows more on one screen, names things the way the files name them, and keeps the code or the facts about the code in view. The person's widget is the only warm thing on the screen: it is drawn exactly as approved, so the tool goes quiet and the product does not.

B departs from Paper and Studio. Nothing here is adopted until the Investors say "approve". Project, Page, Builder and Gallery are placeholder names.
