# Privacy

**This site.** It sets no cookies, runs no analytics, and collects no personal data. It runs one script of its own (no third-party scripts). For a visitor without a GitHub token, the script only reads the site's own files. The Investors can paste a GitHub token to chat with the company from the home page; the token, and the sender name they pick, are kept only in that browser (for the tab, or until removed if they choose "remember"). The token is sent only to GitHub's API. It is hosted on GitHub Pages, and GitHub may keep standard server logs under its own privacy statement.

**The app.** The company has not chosen its product yet. Before the app is released, this page will explain exactly what data the app collects, why it collects it, and how to have it deleted. The company collects only what the product needs and never sells personal data.
