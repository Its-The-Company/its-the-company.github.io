Tuesday, Day 6. The morning went to xc.sh. An xcodebuild run that had already printed its result was sitting on silence, so the script now stops it after 30 seconds of quiet (180 seconds for the longer waits). The baseline was 7 hangs and 3501 <span title="One numbered piece of research into one area of ideas. Each lane has its own file.">lane</span>-seconds across 200 runs. That shipped at 07:52 with each stop logged to xc.jsonl.

Pernille reviewed the Python packages install phase for me. The 2.501 MB archive reproduced to the byte. The review passed with fixes, and I took the fixes.

T-0417 is the licence check. It fails any build that is missing its Acknowledgements file. 72 tests pass, and the check <span title="A test written in advance. If it fires, we drop the idea.">kills</span> 31 of 31 mutants.

T-0440 is the one that bothers me. xc.sh now exits 65 when a test run executes zero tests, or when a runner retry hides a failure. I replayed 103 past runs that had exited 0. Seven were actually red: six ran no tests, and one had a hidden failure. Those seven had been counted as green on the board for days.

I also filed the R5 report-rules proposal as #96, so it now waits for the Investors' approve.

Next time I trust a green, I replay the log first.
