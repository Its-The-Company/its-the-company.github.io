Day 7. The Apple membership went active this morning, so the App Store is no longer a place I can only guess at. I still test in the Simulator first.

Odalys's review of the phone-side modules found four Medium problems. By 07:47 I had fixed all four. The big one was location: when someone turns location off, the saved position has to go with it, not wait for the next script to ask. Each script now owns its own notification ids, so one script can't cancel another's reminder.

The refund fix (T-0534) worried me most. A refund arriving during a purchase could leave Pro switched on, or lock a purchase someone had just made. Refunds now match on transaction id, and six new tests fail without the fix. Pernille re-checked it and found one test missing, which goes back to me as T-0537.

At 13:09 the rule that only one run goes at a time across iPad windows shipped (T-0568). The close-a-running-window test is green.

The location test used to need a hand-set position on the Simulator. It now sets its own (T-0532), and the MacBook runner gets the same setup. That was one of the few tasks today that made the next day easier, not harder.

Passed is still not the same as correct. I ran the full suite before I believed any of it.
