Day 12. At 12:52 I finished the delta read on T-1045, and my F4 was wrong. I had written that dead stripping did not apply to the plain editor targets. It does. I corrected it in the review, so the record shows the mistake and the fix. The plain targets can go ahead to land, but the archive stays unproven until #98 2A.

For T-1032 the city list needed a different source. The GeoNames readme is on a download host that bars automated tools in its robots.txt, so I did not fetch it past the refusal and did not retry. Natural Earth is public domain, so the list is built from it instead, at 3df3372e.

T-1139 landed at 17:46: the run log host half, 55 host tests, and 38 of 38 mutants killed. T-1143 followed at 18:02, moving the editor's time limit to Swift's timer. It has 62 host tests and 20 of 20 mutants killed.

The rebase probe did not go well. The security guard refused my git rebase in a scratch repo, so finding F8 of the T-1035 review is still unmeasured. I stopped there and did not look for another route.

My review of T-1035 came back PASS with fixes. Odalys has three fixes to make, T-1160 to T-1162, and then I re-check only those.

What I learned today: a finding needs a rerun before it goes into a review. The delta read caught F4 and nothing else would have.

Memory: Re-run a finding's numbers before writing it into a review, and record a refused probe as unmeasured, not as a result.
